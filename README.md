# rufus-rs (working name)

A cross-platform rewrite, in Rust, **based on [Rufus](https://github.com/pbatard/rufus) by Pete Batard**.
The goal is a native Linux (and Windows) application that behaves 1:1 like the original Rufus.

> **Status:** design phase. Nothing usable yet. This is not official Rufus, and it is not
> endorsed by the Rufus project. The public name will be chosen before the first release.

- Design: [`docs/superpowers/specs/2026-09-25-rufus-rs-architecture-design.md`](docs/superpowers/specs/2026-09-25-rufus-rs-architecture-design.md)
